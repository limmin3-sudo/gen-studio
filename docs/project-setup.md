# 다른 프로젝트에서 Gen Studio를 편하게 쓰기

처음 한 번만 설정하면, 그다음부터는 Codex에게 평소 말투로 부탁하면 됩니다.

- "디렉터가 화물칸 앞에서 설명하는 튜토리얼 장면 하나 만들어줘"
- "브로커 사진 허벅지까지 보이게 늘려줘"
- "오퍼레이터 배경을 함교로 바꿔줘"

경로, 형식, 크기, 모델은 Codex와 Gen Studio가 알아서 정합니다.

## 1. 프로젝트 AGENTS.md에 안내문 넣기

Codex는 작업 전에 프로젝트의 `AGENTS.md` 를 읽습니다. 아래 블록을 붙여 넣고 폴더 이름만 프로젝트에 맞게 고치세요.
Codex에게 "이 내용을 AGENTS.md에 추가해줘"라고 시켜도 됩니다.

```markdown
## 이미지 작업 (Gen Studio)

- 이미지는 `gen_studio` MCP 도구로 만든다. 외부 이미지 서비스는 쓰지 않는다.
- 사용자는 짧게 말한다. 인물 이름은 `list_characters` 로 찾고, 경로·크기·파일 이름은 아래 규칙대로 직접 정한다.
- 저장 위치와 형식:
  - 파트너 초상화: `assets/partners/<영문-이름>-portrait.webp`, 긴 변 1024px
  - 튜토리얼 장면: `assets/guide/tutorial-<번호 두 자리>.webp`, 세로 3:4, 긴 변 1280px
  - 그 밖의 이미지: `assets/` 아래 비슷한 폴더, WebP
- `export_image` 로 저장한다. 같은 이름의 파일이 이미 있으면 덮어쓰기 전에 사용자에게 묻는다.
- 결과 이미지를 사용자에게 먼저 보여주고, 마음에 든다고 하면 저장하고 페이지에 연결한다.
- 파트너는 실존 인물이 아닌 가상 캐릭터다. 새 이미지도 같은 인물로 유지한다 (`character` 지정).
- 어떤 이미지를 언제 어떻게 만들었는지 해당 폴더의 README에 한 줄씩 기록한다.
```

## 2. 캐릭터 한 번 등록

Codex에게 이렇게 말하면 됩니다.

> 파트너 4명 캐릭터로 등록해줘

Codex가 `assets/partners` 의 사진으로 `create_character` 를 호출합니다. 부르기 쉬운 별명도 같이 넣어 달라고 하면 좋습니다
(예: 플라이트 디렉터 → "디렉터", "director").
이름은 대충 불러도 됩니다. "디렉터"라고 하면 "플라이트 디렉터"를 찾습니다.

등록한 캐릭터는 Gen Studio 웹 화면의 생성 탭 **캐릭터** 메뉴에도 나타납니다. 편집기에서 이미지를 열고
**캐릭터로 등록** 을 눌러 직접 등록할 수도 있습니다.

## 3. 다른 프로젝트에서도

같은 방법으로 어떤 프로젝트에서든 쓸 수 있습니다. 프로젝트마다 `AGENTS.md` 의 저장 규칙만 바꾸면 됩니다.
캐릭터는 Gen Studio에 저장되므로 여러 프로젝트에서 같이 씁니다.
