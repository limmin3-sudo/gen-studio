### 뼈대를 직접 끌어서 자세를 만드는 편집기 (LAKIS 3D 포즈 편집 참고)
- 사용자가 "나중에 꼭 만들자"고 정한 기능 (2026-11-09).
- 화면에 사람 뼈대(관절 점과 선)를 띄우고, 관절을 마우스나 손가락으로 끌어 자세를 만든다.
- 시작점: 빈 기본 자세, 저장해 둔 자세, 또는 사진에서 읽은 뼈대(지금 있는 SDPose 포즈 맵).
- 만든 자세로 할 수 있는 것: 새로 그리기(지금의 + 포즈와 같은 경로), 지금 이미지의 사람 자세 바꾸기.
- 여러 명을 지원하고, 사람마다 프롬프트를 따로 줄 수 있게 한다(영역별 프롬프트와 연결).
- 손가락·얼굴 방향, 카메라 각도(정면·측면·위에서)는 2차로 미룬다.
- 자세는 이름을 붙여 저장하고 다시 불러올 수 있게 한다.
- LAKIS 코드는 복사·수정 금지 라이선스라 참고만 하고 직접 새로 만든다.
